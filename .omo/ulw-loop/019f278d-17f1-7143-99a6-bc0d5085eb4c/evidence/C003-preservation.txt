# chapter05-week1-inital-design.md
일반적인 해시 문제점
서버 추가/삭제 시 전체 해시 재계산 필요

안정해시
해시 링 : 특정 해시함수로 만들어진 일렬로 나열된 해시 공간들을 구부려 원형으로 만든것
안정해시
해시 링 사용
해시 서버를 해시 링 위에 배치
이후 해시 키들을 각 공간에 배치하고 원에서 시계방향으로 가장 먼저 만나는 서버에 저장

서버 추가/삭제 시
추가된 서버의 바로 다음 서버의 데이터만 재배치가 일어난다


안정 해시의 문제점 
서버 추가/삭제 시 키가 여러 서버에 균등하게 분산되지 않고 특정 서버에 몰릴 가능성 존재

가상노드
물리적 서버 위에 가상의 노드 만듬
가상 노드를 서버 대수만큼 쪼개 가상 노드의 분리된 파티션 인덱스와 동일한 인덱스 번호의 서버에 배치하여 데이터 균등하게 저장
